# From Pixels to Provenance — development log

Running history of every change to the pipeline: what was wrong, how we found it, what we changed and what it did
to the results. It is the source for the report's "how the model was developed" narrative. **Newest entries go at
the bottom of each section; nothing is deleted** (superseded results stay, marked as such).

Conventions: *Run* = a full or partial pipeline run on the real GOODS-South data (3 ACS/WFC `_drc` images,
F475W / F606W / F814W, one pointing) with the real GZH, Gaia DR3 and CANDELS catalogues. "Mac" = Sangeeta's
machine (Apple MPS); "workspace" = Claude's test copy (CPU). Test-set numbers are n = 38 galaxies, so their 95 %
bootstrap intervals are wide — compare intervals, not single values.
